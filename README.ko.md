# Secret

[English](README.md)

Secret은 암호화된 USB나 외장 디스크를 위한 Windows용 단일 exe 앱입니다. 드라이브의 파일을 갤러리로 보여 주고, **[지금 동기화]**를 누를 때만 내 디스코드 서버에 암호화해서 백업합니다.

원본은 드라이브이고 디스코드에는 암호화된 사본만 올라갑니다 (드라이브 → 디스코드 단방향). 드라이브를 잃어버려도 봇 토큰, 서버 ID, 비밀번호만 있으면 폴더 구조 그대로 되살릴 수 있습니다.

> [!WARNING]
> 디스코드는 파일 보관 서비스가 아닙니다. 봇으로 백업을 올리는 것은 디스코드 이용약관이나 개발자 정책에 어긋날 수 있고, 디스코드는 언제든 메시지·서버·봇을 지울 수 있습니다. 책임은 사용자에게 있으며, 드라이브를 원본으로 두고 나만 보이는 비공개 서버를 쓰세요.

## 기능

- **디스코드 암호화 백업:** 파일은 올리기 전에 AES-256-GCM으로 암호화합니다. 채널 이름은 무작위(`v-3f9a2c`)이고, 진짜 파일 이름·경로·날짜는 암호화된 목차 안에만 있습니다.
- **모든 파일 백업:** 사진·영상·문서·음악은 메뉴로 나눠 보이고, 그 밖의 파일은 '기타'로 백업합니다. 임시·잠금 파일은 뺍니다.
- **드라이브 없이 복원:** 봇 토큰, 서버 ID, 비밀번호만 있으면 됩니다. 끊겨도 이어받고, 파일마다 SHA-256으로 확인합니다.
- **버전 기록과 휴지통:** 동기화할 때마다 보관함 전체 상태가 버전으로 남아 어느 시점으로든 되돌릴 수 있습니다. 동기화 때 지운 파일은 휴지통에 남습니다. 몇 개까지 남길지는 설정에서 정합니다 (기본: 버전 30개, 휴지통 100개).
- **백업 점검:** 빠른 점검은 모든 조각이 디스코드에 제 크기로 남아 있는지 보고, 정밀 점검은 전부 받아 메모리에서 풀어 대조합니다.
- **뷰어:** 사진(HEIC 포함), 영상, 음악, PDF, zip(풀지 않고 폴더처럼)을 열고, 텍스트는 바로 편집합니다.
- **도구:** 텍스트 암호화(디스코드에 붙여 넣는 `ENC1:` 암호문), 파일 암호화(200MB까지), 탐색기에서 폴더 숨기기, 중복 파일 찾기, 비밀번호 변경.
- **흔적을 남기지 않음:** 썸네일과 미리보기는 메모리에만 둡니다. 복사한 비밀번호는 클립보드에서 지우고 Windows 클립보드 기록에도 남기지 않습니다.
- **언어:** 한국어, English, 简体中文, 日本語, Русский.

## 디스코드가 볼 수 있는 것

디스코드(와 서버를 볼 수 있는 사람)는 암호문 메시지의 크기, 파일 개수, 동기화한 시각, 위 두 단계 폴더의 개수(카테고리·채널 수)를 볼 수 있습니다. 파일 내용, 이름, 경로는 볼 수 없습니다.

## 시작하기

1. `Secret.exe`를 드라이브 맨 위에 두고 실행합니다. 드라이브 전체가 보관함이 됩니다.
   Windows 드라이브(보통 `C:`)에서 실행하면 exe가 있는 폴더만 씁니다.
2. [Discord 개발자 포털](https://discord.com/developers/applications)에서 봇을 만들고, 비공개 서버에 아래 권한으로 초대합니다.
   채널 보기, 채널 관리, 메시지 보내기, 파일 첨부, 메시지 기록 보기, 메시지 관리, 공개 스레드 만들기, 스레드에서 메시지 보내기, 스레드 관리
3. Secret에서 **[연결하기]** → 봇 토큰과 서버 ID를 넣고 **[연결 확인]** → 메인 비밀번호를 정합니다.
4. **[지금 동기화]** → 올릴 것과 지울 것을 확인하고 시작합니다.

**메인 비밀번호를 잊으면 누구도 백업을 풀 수 없습니다.** 긴 문장형 비밀번호를 쓰세요.

봇 토큰, 열쇠, 목차 캐시는 드라이브의 숨김 폴더 `.secret`에 암호화되어 저장됩니다.

## 폴더와 디스코드

| 드라이브 | 디스코드 |
|---|---|
| 맨 위 폴더 | 카테고리 |
| 두 번째 단계 폴더 | 채널 |
| 더 깊은 폴더 | 같은 채널 (경로는 목차에 기록) |
| 작은 파일 | 메시지 하나 |
| 큰 파일 | 암호화 조각을 담은 스레드 (부스트 서버는 조각이 커짐) |

## 안전장치

- 드라이브에서 지운 파일은 동기화 확인 창에서 확인해야만 디스코드에서도 지웁니다.
- 올리기가 하나라도 실패하면 그번에는 아무것도 지우지 않습니다.
- 새 목차를 먼저 올린 뒤에 지우므로, 중간에 끊겨도 언제나 복원할 수 있고 남은 일은 다음 동기화가 마칩니다.
- Secret은 자기가 만든 채널과 메시지만 다룹니다. 그 채널에 직접 글을 쓰면 그 채널은 건드리지 않습니다.
- 최신 목차 2개를 남겨, 최신 목차가 손상되면 직전 목차로 복원합니다.

## 소스에서 빌드

Windows와 Python 3.12가 필요합니다.

```
build.bat
```

가상 환경을 만들고 `requirements.txt`를 설치한 뒤, 테스트를 돌리고 `dist\Secret.exe`를 만듭니다.

개발할 때:

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m secret.app --root dev_usb
.venv\Scripts\python -m pytest
```

코어(`secret/core`)는 Qt를 쓰지 않습니다. 테스트는 메모리 안의 가짜 디스코드로 동기화·복원·장애 주입을 검증합니다.

## Windows Defender

PyInstaller로 만든 exe는 가끔 바이러스로 잘못 잡힙니다. 그럴 때는 Windows 보안에서 `Secret.exe`를 허용하거나, 소스에서 직접 빌드하세요.
